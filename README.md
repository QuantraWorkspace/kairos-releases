# Kairos Macro Terminal for Windows

## Install

1. Download **KairosMacroTerminal-Setup-….exe** from the [latest release](https://github.com/QuantraWorkspace/kairos-releases/releases/latest).
2. Double-click it. If Windows says "Windows protected your PC", click **More info → Run anyway** (the installer is not code-signed).
3. It installs for your account only (no admin password) and opens by itself. Afterwards, open it from the Start menu.

For the AI features, get a free Gemini key at [aistudio.google.com](https://aistudio.google.com), then in the app go to **Risk & models → API keys**, paste it and click **Save**.

## Updates

The app checks for a new version when it starts and every 4 hours, downloads it in the background, and installs it when you close the app. Your journal, saved keys and history are kept. If you reopen the app within about 30 seconds of closing it while an update installs, close and reopen it once more.

Every release here was built automatically, then installed and run on Windows before it was published.
